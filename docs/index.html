Many machine-learning models learn by predicting with their current parameters, measuring error with a loss, computing gradients, and updating the parameters. The trained model is then used for inference; it does not normally retrain for each answer.

Step 01

A model is a function with dials

A model maps an input to an output using adjustable numbers called parameters or weights. Training searches for values that perform well on examples; the resulting model can then make predictions on new inputs.

Our running example uses synthetic telematics data: hard-braking events per 100 miles as the input and a made-up risk score as the output. A straight-line model has a slope w and an intercept b:

predicted_risk = w * braking_events + b
loss = mean((predicted - actual)²)

This loss is mean squared error: it averages squared prediction errors. Squaring makes positive and negative errors contribute positively and gives larger misses more weight.

Model

A function and its parameters. Here it is a line; other models have many more parameters.

Loss

A number used to measure error or another training objective on a set of examples.

Optimizer

A rule for adjusting parameters, often using gradients to reduce the loss.

Four ways models learn from data

  • Supervised: learn from examples with labels, such as a claim marked fraudulent or not fraudulent.
  • Unsupervised: find structure in data without labels, such as groups of similar records.
  • Self-supervised: derive a training target from the data itself, such as predicting a missing or next token.
  • Reinforcement learning: learn from feedback or rewards for actions. Some chat models use human-preference feedback in a later training stage.

Security angle The model, training data, labels, and evaluation data are separate assets. Access to any of them can affect the behavior or confidentiality of the resulting system.

Step 02

Gradient descent: walk downhill on the loss

Every pair of w and b produces a loss. Picture a surface whose height is that loss. The gradient points uphill at the current position; gradient descent steps in the opposite direction. The learning rate controls the size of the step.

w = w - learning_rate * dLoss/dw
b = b - learning_rate * dLoss/db

For mean squared error:
dLoss/dw = 2 * mean((predicted - actual) * x)
dLoss/db = 2 * mean(predicted - actual)

What changes at scale

  • Models may have millions or billions of parameters. The same gradient idea applies, although the loss surface is not visible.
  • Stochastic gradient descent estimates an update from a small batch rather than the whole dataset. An epoch is a full pass through the training data.
  • Optimizers such as Adam adapt updates per parameter. They can help with uneven scales, but do not guarantee convergence or replace feature and learning-rate choices.

Security angle An attacker can use a gradient with respect to the input to search for a perturbation that changes a prediction. A gradient gives a local direction; it does not by itself guarantee the smallest possible change.

Step 03

Neural networks and backpropagation

A straight line has limited expressive power. A neural network combines weighted sums with nonlinear activations, such as ReLU: max(0, z). Stacking layers lets the model represent much more complex relationships.

Backpropagation applies the chain rule backward through the network to compute gradients of the loss with respect to its trainable parameters. Libraries such as PyTorch automate this calculation.

Training is not the goal. Generalizing is.

A model is useful when it performs on data it has not seen. One sign of overfitting is training loss falling while held-out validation loss rises. Validation, appropriate data, regularization, and careful evaluation help; none is a complete guarantee.

Security angle Models can leak training information. Membership inference may reveal whether a record was used in training, and some language models can reproduce memorized text. Risk depends on the model, data, and attacker access.

Step 04

How a language model produces text

Many large language models are trained to predict a next token from preceding context. Generation repeats that prediction, adding one token at a time.

  1. Tokenize: split text into tokens, often word pieces. The split depends on the tokenizer.
  2. Embed: represent tokens as learned vectors, with position information.
  3. Transform: transformer layers refine the representations. In attention, a token's query is compared with keys for permitted context positions; the resulting weights mix the corresponding value vectors.
  4. Predict: produce a raw score, or logit, for each candidate token. Softmax converts scores into probabilities; a decoding strategy chooses the next token.

Pretraining often uses a next-token objective over a large corpus. Additional instruction tuning and preference tuning, including methods such as RLHF, may shape behavior. Models and training pipelines differ.

Context is not an authorization boundary

The context can include system messages, conversation, retrieved passages, and tool results. Providers often encode role markers or structured messages and train models to respect instruction hierarchies. Those labels help, but they do not reliably prevent untrusted text from influencing behavior.

Security angle Prompt injection exploits the model's treatment of untrusted instructions as authority. Delimiters and prompts help with clarity, but permissions, tool controls, output handling, and egress restrictions must be enforced outside the model.

Step 05

Embeddings: meaning as a position in space

An embedding model maps text, images, or other inputs to vectors. Useful embeddings often place related items near one another according to a chosen similarity measure. Dimensions in a learned embedding usually do not have simple human-readable labels.

Some embedding models use contrastive training: matched pairs are encouraged to be closer and mismatched pairs farther apart. Other training objectives exist. No single vector or metric captures every aspect of meaning.

cosine(a, b) = (a · b) / (|a| * |b|)

Cosine measures the angle between nonzero vectors: 1 is the same direction, 0 is orthogonal, and −1 is opposite direction. These numbers do not have universal semantic meanings. For unit-length vectors, cosine equals their dot product.

Searching many vectors

Exact search compares the query with eligible vectors. At larger scales, approximate nearest neighbor (ANN) indexes can be faster but may miss true neighbors. HNSW uses a layered graph; IVF groups vectors and searches selected groups. Measure recall and latency for the actual workload.

Security angle Embeddings are not automatically anonymous. Research has recovered information, and sometimes text, from some embeddings under particular conditions. Classify and protect vectors, indexes, caches, and their source data according to their sensitivity.

Step 06

RAG: retrieve first, then generate

Retrieval-augmented generation retrieves passages at question time and supplies them as context to a model. This can make current or private information available without retraining, but neither a retrieved passage nor a citation guarantees a correct answer.

Indexing Load → clean → chunk → embed → store vectors, text, provenance, and access metadata

Answering Authenticate → authorize search → retrieve → recheck access → rerank → build context → generate and cite

Choices that affect quality and access

  • Chunking: balance context against retrieval precision. Start with sensible paragraph or heading boundaries and measure.
  • Hybrid search: combine lexical search, such as BM25, with vectors. Exact policy numbers or error codes may need lexical matching.
  • Reranking: a more expensive model can rescore a limited candidate set. Only authorized content may reach it.
  • Access: derive permissions from trusted identity, constrain the search or index, and recheck results before any reranker or model sees them. Recheck cached and saved results after access changes.
  • Evaluation: measure retrieval, such as recall at k, separately from answer quality and faithfulness to sources.

Step 08

Check yourself, then keep going

Why can a learning rate that is too high make training diverge?

Steps can overshoot the minimum repeatedly. For the quadratic in the demo, a sufficiently large rate makes the oscillations grow rather than shrink.

What does backpropagation compute?

Gradients of the loss with respect to trainable parameters by applying the chain rule backward through the computation.

How might you notice overfitting?

Training loss keeps falling while held-out validation loss rises. Compare behavior on representative unseen data, not only the training set.

What is a logit, and what does temperature do?

A logit is a raw candidate score. For positive temperatures, dividing logits by temperature before softmax sharpens or flattens the sampling distribution.

How can an embedding model learn that sentences are related?

One approach is contrastive training on related and unrelated pairs. Embedding models can also use other objectives.

When are cosine similarity and dot product equal?

When both vectors have unit length. Cosine is undefined for a zero vector.

What can an ANN index trade away?

Recall: faster approximate search may miss actual nearest neighbors. The tradeoff depends on the index and its settings.

When must RAG authorization be enforced?

Before protected content reaches a reranker, model, or user. Constrain the trusted search or index and recheck results; trimming a top-k set later can also reduce recall.

Why does the filter not stop the poisoned FAQ?

The FAQ is authorized for the user but contains untrusted instructions. Limit what the model can do, enforce tool authorization independently, and restrict outbound channels.

A weekend build

  1. Reimplement the gradient descent example in Python or NumPy and compare the loss to the analytic solution.
  2. Embed a small set of synthetic or personal notes with a local model. Do not use work or other sensitive data.
  3. Retrieve by cosine similarity, then build a prompt for an approved model. Consider provider retention and data-use terms before sending anything.
  4. Plant an instruction in a permitted note and add a second user's private notes. Test what reaches the model without filtering, then enforce permissions and tool limits. Record the results and remaining risks.
