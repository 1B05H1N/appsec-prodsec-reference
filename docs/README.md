# From Gradients to RAG

An interactive introduction to machine learning, language models, embeddings,
retrieval, and their security boundaries.

- [Open the guide](https://1b05h1n.github.io/appsec-prodsec-reference/).
- To use it offline, clone the repository and open `docs/index.html` in a browser.
- To check the demo calculations, run `node --test tests/gradients-to-rag.test.cjs`
  from the repository root with Node.js 20 or newer.

The exercises use synthetic data and run locally in the browser. They do not
call a model, use credentials, or send demo inputs to a service.
